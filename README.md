Manipulador Octaedro (Octahedron Manipulator)

A small computer graphics application that lets the user visualize and manipulate a 3D octahedron, which is then projected onto a 2D screen.

About

This project was built to practice core computer graphics concepts: representing a 3D solid, applying geometric transformations to it, and projecting the result onto a 2D plane for display — the same fundamentals behind real-time rendering pipelines.

Concepts covered
3D object representation
Geometric transformations (translation, rotation, scale)
2D projection of 3D geometry
Basic rendering/visualization logic
Tech stack
Language: Python

Getting started

bash
git clone https://github.com/Eduardo-Rais/Manipulador-Octaedro.git
cd Manipulador-Octaedro
python Octaedro.py

Requirements: Python 3 and any libraries imported at the top of Octaedro.py (install via pip install <library> if needed).
